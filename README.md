# REQUIEZ A-26 - imagenes y fichas tecnicas para Shopify

- imagenes/: fotos 1000x1000. Nombre = handle del titulo del producto + SKU de la variante.
- fichas-tecnicas/: PDF de requiez.com cuyos codigos coinciden al 100% con el producto.
- indice_urls.csv: tarjeta, SKU, tipo, archivo y URL directa de cada imagen y ficha.
